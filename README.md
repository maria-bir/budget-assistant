# Бюджетный помощник

Данный проект представляет собой консольное приложение для учёта ежедневных расходов за месяц (дни 1–31)

## Видео
https://disk.yandex.ru/i/K3wKKYbAHe5NaA

## Функционал

1. Хранение информации о расходах за месяц в формате: день, сумма, категория.
2. Добавление расхода
3. Сумма трат за заданный период
4. Вывод дня с максимальной суммой трат (выводяится день и сумма)
5. Сортировка категорий по убыванию суммы трат.
6. Просмотр расходов за определенный день (выводится список трат по категориям в порядке убывания и итоговая сумма)
7. Просмотр всех расходов
8. Отмена последнего добавления

## Реализация

Для хранения ежедневных расходов пользователя за месяц мы использовали бинарное дерево поиска (BST) с ключом по дню.  
Для добавления расходов и запроса суммы расходов за период реализован массив префиксных сумм.  
Поиск дня с максимальным расходом реализован с помощью линейного поиска. Для сортировки трат по категориям мы сделали сортировку вставками, а для отмены последнего расхода стек, а для отмены последнего расхода используется стек.
